# Free Model Distiller

Episode: https://www.youtube.com/watch?v=eYGDOk2HsOg

Bun plus `yt-dlp` and FFmpeg are required. The root implementation and `codex`, `muse`, `oxalpha` variants are separate experiments; model labels record the original experiment and do not promise current provider availability.

```bash
bun install
bun run cli --help
bun run server
```

Read each variant before choosing it. An OpenRouter key is required for analysis; do not assume a `:free` model is still available or every fallback is free. Downloading/transcribing source content and API calls are not triggered by the catalog. `_private` and temporary experiment runs were excluded. Placeholder configs are in `config/environment.example` per variant. The source livestream is linked above; the recap is https://www.youtube.com/watch?v=mz5xo-QX1VM.
